# Examples

Seventeen Python scripts (`01_*.py` … `17_*.py`) that demonstrate the API,
and YAML scenarios (`*.yaml`) for the configuration system. Run them from
the repository root:

```bash
python examples/01_basic_orbit.py --help
python examples/run_config.py examples/minimal_orbit.yaml --steps 5000
```

What each one shows, with plots, is on the
[examples page](https://pedro-g-lima.github.io/COSMIC_WARP/examples/) of the
documentation.
