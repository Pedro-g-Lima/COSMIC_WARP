# Citation & license

## Citation

If you use COSMIC WARP in your research, please cite it (GitHub's "Cite this
repository" uses the same
[`CITATION.cff`](https://github.com/Pedro-g-Lima/COSMIC_WARP/blob/main/CITATION.cff)):

```bibtex
@software{cosmic_warp,
  title   = {COSMIC WARP: GPU-Accelerated Spacecraft Simulator},
  author  = {Lima, Pedro and Arora, Aman},
  year    = {2026},
  version = {0.1.0},
  doi     = {10.5281/zenodo.23950779},
  url     = {https://github.com/Pedro-g-Lima/COSMIC_WARP}
}
```

Please also cite the tools COSMIC WARP builds on: NVIDIA Warp
[[18]](references.md#ref-18) and NumPy [[19]](references.md#ref-19); the
example figures use Matplotlib [[20]](references.md#ref-20). BibTeX entries
for these and for every source behind the physics models are on the
[references](references.md) page ([`references.bib`](references.bib)).
